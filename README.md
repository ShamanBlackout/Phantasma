# 🕯️ Phantasma

**Phantasma** is a blockchain-integrated game experience where spectral mechanics meet secure asset ownership. Built with Unity and smart contract interoperability, it explores decentralized gameplay, NFT-based progression, and async-safe architecture for real-time responsiveness.

## 📘 About This Repository

This repository is designed to onboard developers and users into the **Phantasma ecosystem**. It includes:

- 🧠 **Smart Contract Onboarding**: Sample contracts, deployment guides, and usage patterns tailored for Phantasma’s blockchain.
- 🔗 **PhantasmaLinkClient (Personal Build)**: A customized version of the PhantasmaLinkClient with enhancements for wallet connectivity, NFT interactions, and Unity integration.
- 🧰 **Developer Utilities**: Scripts, test harnesses, and async-safe patterns for building secure, responsive blockchain-enabled apps.
- 🧪 **Learning Resources**: Code walkthroughs, architecture diagrams, and best practices for integrating Phantasma into your own projects.

Whether you're a game dev, smart contract engineer, or curious builder, this repo is your launchpad into decentralized gameplay.

## 🚀 Features

- 🎮 Unity-powered gameplay with custom UI overlays and particle systems
- 🔗 Blockchain integration with wallet connectivity and NFT minting
- 🧠 Async-safe dispatcher patterns using `UniTask`, `Awaitable`, and cancellation-safe flows
- 🐳 Docker-optimized workflows for multi-platform deployment
- 🔐 Federally-aligned secure coding and ACL-aware backend logic

## 🧱 Tech Stack

| Layer         | Tech                          |
|---------------|-------------------------------|
| Game Engine   | Unity (URP, WebGL, C#)         |
| Blockchain    | EVM-compatible smart contracts |
| Wallet        | Web3.js / WalletConnect        |
